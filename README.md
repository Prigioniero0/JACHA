JACHA Console is an experimental Cybersecurity multitool for windows and linux, a work in progress to deliver different tools in a single, user friendly and cool Application. This project is developed with AI Antigravity and Chatgpt, so feedback, bugs and issues are welcome

DEPENDENCIES

will be installed when running the sudo ./install.sh command

INSTALLATION

The Zip File contains the Linux Versione while the exe is the windows version.

Download and extract the zip file, give it full permission and execute the sudo ./install command
this will install the dependencies and install the application so you can run it from every terminal position

FEATURES:

Nmap integrated CLI

Website Scanner Section: 2 modes basic scanner and nikto integrated

SSH Tools Section: ssh client and server config generator for windows and linux

HTTPS connector Section: HTTPS Client and Server config generator for windows and linux

Steganography Section: Hide a file or a zip in a image or cover file and decrypt

Recon Section: Whois, DNS, Reverse DNS

Net-Discovery Section: discover alive hosts in a network

Subdomain Section: 4 different subdomain tools, Sublist3r, knockpy, CRT.sh and a custom bruteforce tool

File Crypto Section: Encrypt a file or a document with a secure password and descrypt

Packet Crafter Section: send custom packets, icmp, arp, udp and tcp, and see the response

Local Server Section: Spawn local server on different ports, each with its own terminal and logging

Mac Change Section: change mac or ip on the system

Metasploit Section (Just for Linux) integrated metasploit terminal

Netcat Section: (Just for Linux)
